# Andrea RBT 🐘💜

A study app for the BACB RBT exam (2026, Test Content Outline 3rd Edition).

- Lessons in simple English for all 6 domains, with a "Listen" voice tutor (Coach Mia)
- Flashcards with spaced repetition
- 168 original scenario questions, with instant feedback on every option
- Full 85-question mock exam (90 min), weighted like the real exam
- Mistakes bank, cheat sheet, notes → flashcards, badges, streaks, dark mode

Progress is saved in the browser (localStorage). No backend.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Import the repo in Vercel (framework: Vite). Build `npm run build`, output `dist`.
